# Планировщик сессии (Kivy)

Интерфейс по макету: предметы со шкалами прогресса, календарь с делами и метками,
папки предметов с делами (тумблеры, приоритет, дедлайн) и заметками.

## Запуск в PyCharm
1. File → Open → папка `session_planner`.
2. Создай интерпретатор (venv), выполни `pip install -r requirements.txt`.
3. Запусти `main.py`. Окно открывается размером телефона (390×844), Esc = «Назад».

## Файлы
- `main.py` — приложение и навигация: `open(экран, **контекст)`, `open_root(экран)`, `back()`.
- `theme.py` — цвета макета.
- `widgets.py` — карточки, кнопки, шкала, тумблер, чип приоритета, ячейка дня, поля ввода.
- `store.py` — данные (пока в памяти, примеры из макета). Позже заменить на SQLite/JSON.
- `dates.py` — форматы дат и разбор ввода (`ДД.ММ.ГГГГ`, `ЧЧ:ММ`).
- `screens/base.py` — каркас экрана: шапка, тело, нижние вкладки.
- `screens/top.py` — Предметы, Календарь, Заметки.
- `screens/subject.py` — папка предмета (вкладки «Дела» / «Заметки»).
- `screens/forms.py` — формы дела, метки, заметки.

## Что работает
- Тумблер у дела меняет прогресс предмета и общий прогресс.
- Дела и метки появляются в календаре по дедлайну; нажатие на день показывает его список.
- Дедлайн дела и метки можно изменить (нажать на дело или «Изм.» у метки).
- «+ Метка», «+ Добавить дело», «+ Заметка» создают записи (пока до закрытия приложения).
