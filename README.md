# Планировщик сессии (основа, Kivy)

Каркас без дизайна: кнопки и переходы между пустыми страницами.

## Запуск в PyCharm
1. File → Open → выбери папку `session_planner`.
2. Создай интерпретатор (venv) и выполни `pip install -r requirements.txt`.
3. Запусти `main.py`. На компьютере окно открывается размером телефона (390×844).
   Esc работает как системная кнопка «Назад».

## Карта экранов
Вкладки внизу (Предметы / Календарь / Заметки):
- **Предметы** → *Предмет* → **Дела** → *Новое дело*
                         → **Заметки** → *Заметка*
- **Календарь** → *Новая метка*
- **Заметки** (папки по предметам) → *Заметки предмета* → *Заметка*

## Структура
- `main.py` — приложение и навигация: `open(имя, **контекст)`, `open_root(имя)`, `back()`.
- `screens/base.py` — общий каркас экрана (кнопка «Назад», заголовок, нижние вкладки).
- `screens/top.py`, `subject.py`, `forms.py` — сами экраны.
- `data.py` — временный список предметов.

## Как добавить экран
1. Создай класс от `BaseScreen` (или `SubjectBoundScreen`, если экран про один предмет).
2. Добавь его в словарь `SCREENS` в `screens/__init__.py`.
3. Открывай кнопкой: `self.button("Текст", self.go("имя_экрана"))`.

## Сборка APK
Через Buildozer (Linux, macOS или WSL на Windows): `buildozer android debug`.
