# Hamoon — планировщик сессии

## Запуск
Откройте папку Hamoon в PyCharm и создайте своё виртуальное окружение.
Установите зависимости и запустите приложение:

```sh
python -m pip install -r requirements.txt
python main.py
```

## Использование
- При запуске открывается экран «Мои сессии». Нажмите «+ Создать сессию» или выберите существующую. Пример зимней сессии оставлен отдельно.
- В «Предметах» нажмите «+ Добавить предмет». Название обязательно, дата экзамена — нет.
- Внутри предмета нажмите «Дата». Введите новую дату или очистите поле и нажмите «Сохранить». Экзамен без даты не отображается в календаре.
- Для возврата к списку сессий нажмите «< Выбрать сессию» на экране предметов.
- Нижняя панель содержит только «Предметы» и «Календарь». Заметки доступны внутри предмета.
- Чтобы удалить метку: выберите день в календаре → «Изм.» у метки → «Удалить метку» → подтвердите удаление.
- Для создания метки выберите день и нажмите «+ Метка».
- Дела, заметки, предметы и метки принадлежат выбранной сессии.
- Все изменения автоматически сохраняются в planner.json в пользовательской папке данных Kivy. Повторный запуск открывает список сессий.
- Esc / системная кнопка «Назад» возвращает на предыдущий экран.

## Проверка
Проверены синтаксис Python и логика добавления предметов, необязательных дат, удаления меток, разделения сессий, сохранения и загрузки JSON.

## Структура
- main.py — запуск и навигация.
- store.py — данные и сохранение JSON.
- dates.py — форматы дат.
- widgets.py, theme.py — виджеты и оформление.
- screens/ — экраны и формы.
- buildozer.spec — настройки сборки Android.

## Сборка Android
В подготовленной среде Buildozer: `buildozer android debug`.

Внутри предмета кнопки «Дата» и «Удалить предмет» имеют одинаковый размер и расположены в одну строку. Удаление требует подтверждения и удаляет дела и заметки только этого предмета в выбранной сессии.
