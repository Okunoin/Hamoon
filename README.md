## О приложении

**Hamoon** — учебный планировщик для студентов, который помогает организовать подготовку к экзаменам. Вместо отдельных списков задач, записей с датами и заметок приложение объединяет подготовку вокруг сессии и её предметов.

Создайте сессию, добавьте дисциплины и разбейте подготовку на конкретные дела. Отмечайте выполненное, следите за прогрессом и смотрите ближайшие события в календаре. Если дата экзамена ещё неизвестна, предмет можно добавить без неё и указать дату позже.

Приложение написано на **Python с использованием Kivy**. Интерфейс рассчитан на вертикальный экран; при запуске на компьютере открывается окно размером 390 × 844. В проекте есть конфигурация Buildozer для дальнейшей сборки Android-приложения.

## Возможности

| Раздел | Что можно делать |
| --- | --- |
| **Сессии** | Создавать отдельные сессии и переключаться между ними. У каждой — свои предметы, дела, заметки и метки. |
| **Предметы** | Добавлять собственные дисциплины, открывать их карточки и удалять предметы с подтверждением. |
| **Экзамены** | Указывать, изменять или убирать дату экзамена. Без даты экзамен не отображается в календаре. |
| **Учебные дела** | Создавать и редактировать задачи, назначать дедлайны и приоритеты, отмечать выполнение. |
| **Прогресс** | Смотреть процент выполненных дел по предмету и по всей выбранной сессии. |
| **Календарь** | Переключать месяцы и просматривать экзамены, дела и метки выбранного дня. Для дела можно отключить показ в календаре. |
| **Метки** | Добавлять отдельные события с датой, необязательным временем, комментарием и цветом; редактировать и удалять их. |
| **Заметки** | Хранить текстовые записи внутри предметов: формулы, вопросы, планы повторения. |
| **Сохранение** | Автоматически сохранять изменения в локальный JSON-файл. Для работы с данными аккаунт и сервер не требуются. |

> Прогресс отражает долю выполненных дел, а не оценку знаний: каждое дело учитывается одинаково независимо от приоритета.

## Быстрый старт

Для запуска понадобятся Python, `pip` и виртуальное окружение. Команды выполняются из папки проекта, в которой находится `main.py`.

### 1. Создайте окружение

```sh
python -m venv .venv
```

Активируйте его командой для своей системы:

| Система / терминал | Команда |
| --- | --- |
| macOS / Linux | `source .venv/bin/activate` |
| Windows PowerShell | `.venv\Scripts\Activate.ps1` |
| Windows cmd | `.venv\Scripts\activate.bat` |

### 2. Установите зависимости

```sh
python -m pip install -r requirements.txt
```

### 3. Запустите приложение

```sh
python main.py
```

**В PyCharm:** откройте папку проекта, выберите созданное окружение в настройках интерпретатора и запустите `main.py`.

## Как пользоваться

### Создайте свою сессию

При запуске открывается экран **«Мои сессии»**. Нажмите **«+ Создать сессию»**, введите название и сохраните. Например: «Летняя сессия 2027».

При первом запуске доступна отдельная демонстрационная сессия с примерами. Своя новая сессия создаётся пустой. Чтобы переключиться между сессиями, на экране предметов нажмите **«< Выбрать сессию»**.

### Добавьте предметы и экзамены

На вкладке **«Предметы»** нажмите **«+ Добавить предмет»**. Укажите название и, если она известна, дату экзамена в формате `ДД.ММ.ГГГГ`.

Внутри предмета доступны две кнопки:

- **«Дата»** — открывает форму изменения даты экзамена. Чтобы убрать дату, очистите поле или нажмите «Убрать дату экзамена», затем сохраните.
- **«Удалить предмет»** — запрашивает подтверждение и удаляет предмет вместе с его делами и заметками в выбранной сессии. Отдельные метки календаря сохраняются.

### Составьте план подготовки

Откройте предмет → **«Дела»** → **«+ Добавить дело»**. Укажите название, дедлайн и приоритет: низкий, средний или высокий. При необходимости отключите показ дела в календаре.

Нажмите на дело, чтобы отредактировать его. Переключатель выполнения обновляет прогресс предмета и общий прогресс сессии.

### Работайте с календарём

Откройте вкладку **«Календарь»** и выберите день. Под сеткой появятся события этой даты:

- **Заливка ячейки** обозначает экзамен.
- **Круглые маркеры** обозначают дела.
- **Квадратные маркеры** обозначают отдельные метки.

Для новой метки нажмите **«+ Метка»**. Для изменения существующей — **«Изм.»** рядом с ней. В открывшейся форме есть кнопка **«Удалить метку»**, после которой потребуется подтверждение.

### Сохраняйте заметки

Откройте предмет → **«Заметки»** → **«+ Заметка»**. Записи доступны внутри предметов; отдельной вкладки заметок в нижней панели нет.

**Навигация назад:** кнопка в шапке, `Esc` на компьютере или системная кнопка «Назад» на Android.

## Хранение данных

Данные автоматически записываются в **`planner.json`** в пользовательской папке приложения, которую определяет Kivy через `App.user_data_dir`. Файл находится отдельно от исходного кода, поэтому перенос только папки проекта не переносит сохранённые сессии.

Сессии разделяют свои данные, но сохраняются в одном файле. Облачной синхронизации и встроенного резервного копирования пока нет. Удаление предметов и меток требует подтверждения; восстановление удалённых записей пока не реализовано.

## Устройство проекта

| Файл / папка | Назначение |
| --- | --- |
| `main.py` | Точка входа, управление экранами и историей переходов. |

| `screens/base.py` | Общий каркас экранов и нижняя навигация. |
| `screens/top.py` | Список сессий, предметы и календарь. |
| `screens/subject.py` | Содержимое предмета, дела, заметки и подтверждение удаления. |
| `screens/forms.py` | Формы создания и редактирования записей. |
| `screens/__init__.py` | Регистрация экранов. |
| `requirements.txt` | Зависимости для запуска на компьютере. |
| `buildozer.spec` | Конфигурация сборки Android. |

## Сборка Android

В подготовленной среде с установленным Buildozer и необходимыми Android-инструментами:

```sh
buildozer android debug
```

В конфигурации указаны вертикальная ориентация и архитектуры `arm64-v8a` и `armeabi-v7a`. Перед распространением приложения нужно настроить идентификатор пакета, проверить зависимости и протестировать сборку на реальном устройстве.

> Наличие `buildozer.spec` не означает, что APK уже собран и проверен. Проверки текущей версии включали синтаксис Python и логику хранения данных; полноценная проверка интерфейса и Android-сборки ещё требуется.
